  heap) with 14 GiB slack

  InnoDB flush bottleneck. Throughput bumped post-boot via
  `modify-volume` (CFN inline BlockDeviceMappings doesn't expose it)

  (bootstrap needs apt/curl), SG blocks all inbound. Direct SG-based
  RDS access via inline RDSIngressFromMigrateHost rule (lifecycle-
  atomic). Zero peering — this is the big simplification vs the
