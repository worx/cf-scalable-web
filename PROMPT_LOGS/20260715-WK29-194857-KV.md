was 6 GB. Second run (with tuned pgloader: batch rows = 250, workers = 2,
concurrency = 1) fit comfortably. Kurt's empirical read: 4 GB flat is enough
going forward. If a future migration needs more headroom, migration scripts
can attach a temporary /swapfile2 without touching UserData.

error) — just skips a manual step in the happy path.
