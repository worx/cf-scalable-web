### 21:47:37 - Response

Fair correction — pgloader's stdout during the run is basically silent (buffered). Best real progress signal is the target schema itself:

```bash
# From another SSM session on deploy-host, or from Mac:
psql-env sandbox -d drupal -c \
  "SELECT COUNT(*) AS tables_created FROM information_schema.tables WHERE table_schema='zinew';"
```

Since your tuning is `workers = 2, concurrency = 1`, pgloader works one table at a time — table count goes up monotonically from 0 to 413. Run that query every few minutes to see progress.

For finer detail (what pgloader is doing THIS second on the target):
```bash
psql-env sandbox -d postgres -c \
  "SELECT pid, state, LEFT(query, 120) AS query FROM pg_stat_activity WHERE datname='drupal' AND usename='drupal_user' ORDER BY query_start;"
```

Shows the in-flight COPY/CREATE INDEX/etc. Nice for "is it stuck or working."

On the source side (MariaDB scratch), same idea:
```bash
sudo mysql -e "SHOW PROCESSLIST" | grep -v Sleep | grep -v "^Id"
```

Shows the SELECT queries pgloader is running against MariaDB.

None disturb the run.
