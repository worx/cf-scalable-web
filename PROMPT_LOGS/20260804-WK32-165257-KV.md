Prototype for Kurt's request 2026-08-04: nightly automated dumps of

is irrelevant to nightly dumps.

## Design

Three shell scripts + three Makefile targets.

Scripts (migration/scripts/jumpbox/):

  nightly-dump-runner.sh
    - The wrapper cron invokes. Self-contained.
    - Syncs latest scripts from s3://sandbox-migration-kv-worxco/scripts/
      so cron always uses current versions (uploaded by `make dump-*`
      or `make deploy-nightly-cron` from Mac/deploy-host).
    - Runs dump-mysql, dump-codebase, dump-files, dump-private in
      sequence with CONFIRMED=yes. Breaks on first failure.
    - Failure notification: looks up SNS topic ARN from SSM param
      /migration/nightly-cron/sns-topic-arn; publishes subject +
      last 80 log lines if configured. If unset, failures are
      logged only (silent for MVP).
    - Local log: /var/log/worxco-migration/nightly-<UTC>.log
    - Uses `exec > >(tee ...)` pattern (not `{ } | tee`) so
      FAILED_STEP variable survives — crucial for the SNS message.

  install-nightly-cron.sh
    - Runs on jumpbox via SSM dispatch. Idempotent.
    - Fetches wrapper from S3 to /opt/nightly-dumps/
    - Writes root crontab entry marked
      `# managed-by: install-nightly-cron.sh` so re-runs cleanly
      replace prior entries (schedule changes just work).
    - Default CRON_SCHEDULE = "0 3 * * 2-6" (3am UTC, Tue-Sat).
      Override via env var if timezone differs.

  remove-nightly-cron.sh
    - Removes the marked crontab entries. Preserves the wrapper at
      /opt/nightly-dumps/ so reinstall is fast and manual `sudo
      /opt/nightly-dumps/nightly-dump-runner.sh` still works.
    - Handles the "our entries were the ONLY ones" case correctly
      (uses `crontab -r` rather than piping empty).

Makefile targets (migration/Makefile):

  deploy-nightly-cron   — pre-uploads wrapper to S3, then dispatches
                          install-nightly-cron.sh via SSM. Two-step
                          because install script fetches wrapper
                          from S3 during its run.
  remove-nightly-cron   — dispatches remove-nightly-cron.sh via SSM.
  test-nightly-cron     — dispatches nightly-dump-runner.sh via SSM
                          right now (same behavior as scheduled run).

.PHONY + help section updated.
