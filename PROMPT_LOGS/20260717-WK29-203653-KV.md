**NOT captured (only lives in tmux scrollback):**

**Practical mitigation for this test — tee inside tmux:**

```bash
make ssm-deploy-host
sudo tmux new -s migrate
cd /home/ubuntu/projects/cf-scalable-web/migration
LOG=~/migrate-full-all-$(date -u +%Y%m%d_%H%M%SZ).log
make migrate-full-all 2>&1 | tee $LOG
```

- `2>&1` sends stderr through the pipe too
- `tee` writes to `$LOG` in your ubuntu home dir (outside tmux, at `/home/ubuntu/`)
- Screen shows exactly what tmux would have shown
- After it finishes (or dies): `cat $LOG` or scp it to your Mac

That closes the gap for this specific run. Zero code changes needed.
