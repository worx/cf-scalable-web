feat(print-doc): make target + pandoc helpers for print-ready MD → PDF

Adds `make print-doc DOC=<path.md>` that renders any Markdown file to
a print-ready PDF via pandoc + xelatex. Designed for docs like the
multi-tenant refactor review (many wide tables, prose in every cell,
long /path/like/strings inside \texttt) that break naïve pandoc
invocations with:
  - column 2 overflowing into column 3 (fixed-width columns)
  - tofu glyphs for arrows and check-marks (missing font coverage)
  - long paths as unbreakable atoms overflowing table cells

The helpers under scripts/pandoc/ apply layered fixes:

1. table-widths.lua — Lua filter that assigns 1/N proportional widths
   to every table column, forcing pandoc to emit p{...} columns with
   \raggedright wrapping instead of fixed-width columns that overflow.

2. preamble.tex — LaTeX preamble injected via --include-in-header:
   - newunicodechar mappings for → ← ↔ ⇒ ✓ ✗ … – — so macOS system
     fonts don't emit tofu for glyphs they don't ship
   - hyphenat[htt] enables hyphenation inside \texttt{}
   - Preamble-defined \BreakableTt wraps content in \seqsplit (invisible
     break points between every character) — swapped in via \let at
     longtable start, so section headings stay safe. Scoping via
     \AtBeginEnvironment{longtable}{} means only tables get the
     break-anywhere treatment.
   - \footnotesize inside longtable for a bit more horizontal room
   - emergencystretch + tolerance relaxed for cleaner line breaks

3. render-pdf.sh — thin shell wrapper that finds helper files via
   BASH_SOURCE (so it works from any pwd), checks tool preconditions
   (pandoc + xelatex), applies env-overridable knobs (FONT FONTSIZE
   MARGIN OPEN), and auto-opens in Preview by default.

Makefile target usage:
  make print-doc DOC=docs/plans/multi-tenant-refactor-review-2026-07-31.md
  make print-doc DOC=docs/FSX-LAYOUT.md OUT=~/Downloads/fsx.pdf OPEN=no
  make print-doc DOC=README.md FONT="PT Serif" FONTSIZE=10pt

Requires pandoc (brew install pandoc) + xelatex
(brew install --cask basictex). Both preconditions checked with
actionable install hints on failure.

Verified: the multi-tenant refactor review PDF (5-column Conflicts
table in §6, path-heavy cells in §7 Namespace convention) renders
readably end to end.
