Suggested consolidated commit message:

```
fix(migration): settings.php schema=zinew + Phase 9 restart-php-fpm
              + quiet AUTO=yes preflight + cache_* data exclusion in dump

Five related migration-pipeline improvements from tonight's rebuild:

1. install-drupal.sh: 'schema' => 'zinew' in settings.php DB config
   Drupal's pgsql driver hardcodes 'public.<table>' in introspection
   queries. Without an explicit schema in DB config, drush cr fatals
   ("relation 'public.search_dataset' does not exist") and Drupal's
   install-check falls through, redirecting /admin → /core/install.php.
   Env-driven with 'zinew' default matching pgloader's current output.
   Documented last time, missed in code — now codified.

2. Phase 9: restart-php-fpm (MANDATORY, was missing)
   restore-codebase atomically swaps /var/www/drupal on FSx, but
   PHP-FPM workers still hold pre-swap bytecode in OPcache. Old
   bytecode executes and resolves classes against the NEW composer
   classmap → fatal on every request. clear-drupal-cache is a
   filesystem+DB op only; only restart-php-fpm invalidates OPcache.

3. restore-codebase.sh: loud warning at end
   Standalone runs (not via migrate-full-all) still need manual
   clear-cache + restart-php-fpm. Prior "Recommend:" footer was easy
   to miss; now a boxed warning names both required commands + order.

4. migrate-db-all: quiet AUTO=yes preflight false-alarms
   Phase -1 verify-drupal-installed is expected to fail on a fresh
   AUTO=yes deploy. AUTO branch already handled it correctly, but the
   raw FAIL block looked alarming in walk-away logs. Now suppresses
   the block, prints "First-time install detected", runs install-drupal,
   re-verifies with output visible (so any second-time failure IS surfaced).

5. dump-mysql.sh: exclude cache_* data (structure preserved)
   Cache_* is commonly 30-70% of an aged Drupal DB — every rendered
   page, menu, config-object. Guaranteed stale on arrival and
   TRUNCATE'd by Phase 8 anyway. Two-pass mysqldump into single S3
   stream: Pass 1 = --no-data for cache_* tables (structure only),
   Pass 2 = --ignore-table for those in the full DB dump. Auto-
   enumerates cache_* tables via information_schema so any new ones
   are covered. Skipped MB logged for visibility.
```
