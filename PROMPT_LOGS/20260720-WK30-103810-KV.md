### 10:38:49 - Response

Yes, expected — install-drupal.sh has that marker check to prevent accidental reinstall (which would wipe the codebase, regenerate secrets, drupal-media state, etc.). It's a "protect against operator accident" guard.

For your specific need — just migrate the salt into SSM without touching anything else — three options:

## Option 1 — One-line manual (fastest, no code)

On deploy-host:

```bash
sudo -E aws secretsmanager create-secret \
  --name worxco/sandbox/drupal/hash-salt \
  --description "Drupal hash_salt for env sandbox (migrated from salt.txt)" \
  --secret-string "$(sudo cat /var/www/drupal-private/salt.txt)" \
  --tags Key=Environment,Value=sandbox Key=Application,Value=drupal
```

Then:

```bash
sudo refresh-env-config sandbox
# verify:
grep DRUPAL_HASH_SALT /etc/worxco/envs/sandbox
```

That's it — for the deploy-host side. For PHP-FPM instances to pick up `env[DRUPAL_HASH_SALT]`, they need `configure-php.sh` to re-run (natural instance replacement OR manual restart via SSM). Until then, they still use the file fallback via settings.php.

## Option 2 — Small helper script + make target (better ergonomics, one commit)

Extract just the salt-handling block from install-drupal.sh into `scripts/deploy-host/migrate-hash-salt-to-ssm.sh`. Idempotent — safe to run any time, does the "read file → write SSM if missing" dance without any of install-drupal's other heavy work. Then:

```bash
make migrate-hash-salt-to-ssm ENV=sandbox
```

Sees existing salt.txt, creates SSM secret with its contents, done.

Useful when the same situation comes up on staging or production later — no need to `make reinstall-drupal` (which is destructive) just to move a salt.

## Option 3 — Add SKIP_INSTALLED_CHECK=yes to install-drupal.sh

Bypass the marker check via env var, then install-drupal.sh's salt-resolve block runs alongside all its OTHER steps (composer create-project, drush site:install with `--existing-config` or reject-if-exists, etc.). Messy — install-drupal wasn't designed to run on an already-installed target, and its other steps might fight or fail.
