## Pattern

Consistent DOT_COUNT variable initialized before the loop, incremented
in the print-a-dot branch of the case/if, modulo 5 selects '|' vs '.':

    DOT_COUNT=0
    for _ in $(seq 1 N); do
      ...
      case "$STATUS" in
        Pending|InProgress)
          DOT_COUNT=$((DOT_COUNT + 1))
          if [ $((DOT_COUNT % 5)) -eq 0 ]; then printf "|"; else printf "."; fi
          sleep N
          ;;
        *) ... ;;
      esac
    done

Exception: wait-deploy-host-ready.sh's Stage 1 uses the loop's own `i`
directly (`if [ $((i % 5)) -eq 0 ]`) since the loop was already
enumerated. Slightly simpler than adding a redundant counter.

Two tick intervals of note:
- 3s ticks × 5 = 15s per '|'  (relatively frequent — still useful)
- 30s ticks × 5 = 2.5min per '|' (the primary use case per 3639df3)

## Not modified

Places that don't fit the pattern:

  progress display already
- Loops that print per-second timestamps (like Stage 2 of
  wait-deploy-host-ready.sh which shows "[Nm:SSs] cloud-init still
  running..." — full context per line, no dots)

duplication is livable and this is meant to be a fast polish commit.
