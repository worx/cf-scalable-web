PostgreSQL choked on a null byte in the PHP-serialized blob. Two safer approaches — try the escape encoding first (still human-readable), fall back to hex:

```bash
psql-env sandbox <<'SQL'
SET search_path = zinew;
SELECT wid, type, severity, LEFT(encode(variables, 'escape'), 800) AS vars
FROM watchdog
WHERE type IN ('php', 'commerce', 'views')
ORDER BY wid DESC
LIMIT 5;
SQL
```

