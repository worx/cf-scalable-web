  [WARN]  Falling back to legacy behavior (Drupal root only).

Operator had to guess which of the three overlapping failure modes
(missing jq, missing composer.json, actually no path repos) hit.

## The fix

Split the failure-detection into two explicit cases:

1. ssh/jq exited non-zero → log both the exit code AND the captured
   stderr, plus concrete remediation ("install jq on $SOURCE_HOST" /
   "set SIBLING_MODULES to bypass discovery"). No more swallowed
   errors.
2. ssh/jq exited zero but returned nothing → this IS "composer.json
   has no path-type repositories." Different message.

Uses a mktemp'd stderr file so the actual jq output (URLs) still
lands in stdout untouched, and we get the diagnostic when things
go sideways.
