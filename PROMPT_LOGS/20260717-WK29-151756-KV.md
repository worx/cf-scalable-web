fix(migration): restore-mysql CREATE/ALTER USER syntax for MariaDB 10.11

Phase 5 of restore-mysql.sh used MySQL 8's combined
`IDENTIFIED WITH plugin BY 'password'` syntax which MariaDB 10.11 rejects:

    ERROR 1064 (42000) at line 5: You have an error in your SQL syntax;
    check the manual that corresponds to your MariaDB server version
    for the right syntax to use near 'BY 'localscratchpass'' at line 3

MariaDB requires the `IDENTIFIED VIA plugin USING PASSWORD(cleartext)`
form (VIA is the MariaDB-preferred spelling; WITH is also accepted as
an alias, but VIA reads more naturally with USING PASSWORD()).

Fixed in both the executed SQL heredoc and the dry-run log_info line
that documents what would be run.

Discovered during first-live-run of the DB-only test migration
against sandbox (2026-07-17). Earlier successful pgloader migration
runs must have used a MariaDB version that silently accepted the MySQL
form, OR was against MySQL directly — unclear which without spelunking
history, but 10.11 is the target going forward and this is the syntax
that works.
