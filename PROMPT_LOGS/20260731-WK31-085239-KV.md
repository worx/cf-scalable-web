## What this fixes going forward

Next time you do a destroy-all → deploy-all → publish-dns cycle:
- Records not-yet-created get NXDOMAIN cached for **5 min** (not 24h)
- Once publish-dns UPSERTs the alias, the ~5 min window is the worst case for DNS to resolve fresh anywhere
- AWS VPC Resolver, Google 8.8.8.8, Cloudflare 1.1.1.1, your Mac's ISP resolver — all honor SOA MINIMUM, so all now behave with fresh values
