### 19:50:38 - Response

Great question, and the honest answer is **mostly walk-away safe, but with a nuance**.

## The nuance

Each individual DISPATCH is fully walk-away safe:
- `dispatch-db-backup`, `dispatch-restore-mysql`, `dispatch-run-pgloader`, `dispatch-restore-files`, `dispatch-restore-private` all use `aws ssm send-command`
- The **work** runs in SSM's runner ON the deploy-host — Mac disconnecting doesn't kill it

BUT `migrate-full-all` is a **make chain that runs on Mac**. It's the orchestrator that fires one dispatch, waits for it, fires the next, waits, etc. If the Mac `make` process dies:
- The IN-FLIGHT phase keeps running on deploy-host (survives)
- The NEXT phase never fires (chain broken)

So:
- **Mac sleeping with terminal open** → probably fine (poll loop resumes when Mac wakes; SSM `get-command-invocation` is stateless)
- **Terminal closed / SSH disconnects / power off** → chain breaks; current phase finishes but nothing after that runs
- **`Cmd+Q` on Terminal.app** → chain dies

## Recommendations (best → simplest)

**Best: run from deploy-host inside its tmux.** Deploy-host never sleeps or closes.

```bash
make ssm-deploy-host
sudo tmux new -s migrate
cd /home/ubuntu/projects/cf-scalable-web/migration
make migrate-full-all
# Ctrl+B D to detach, exit SSM, walk completely away
# Later: make ssm-deploy-host → sudo tmux attach -t migrate
```

**Very good: `nohup` from Mac terminal.** Chain survives even if the terminal window closes.

```bash
cd ~/Work/dev/cf-scalable-drupal/migration
nohup make migrate-full-all > ~/migrate-full-all.log 2>&1 &
disown
# Safe to close terminal now
# Check progress: tail -f ~/migrate-full-all.log
```

**Good: local tmux on Mac** (if you have tmux installed locally).

```bash
tmux new -s migrate
cd ~/Work/dev/cf-scalable-drupal/migration
make migrate-full-all
# Ctrl+B D to detach
# tmux attach -t migrate to reconnect from any Mac terminal window
```

**Fine for a controlled couple hours: keep the terminal open.** As long as Mac doesn't fully sleep the network, the chain keeps polling.
