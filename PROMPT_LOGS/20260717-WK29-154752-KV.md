fix(migration): embed pgloader password RAW; bump batch/prefetch to 500

Two changes on the pgloader path:

## 1. Skip URL encoding of DRUPAL_DB_PASS (fixes 28P01 auth failure)

pgloader's URL parser has known round-trip issues with percent-encoded
sequences (comma, some punctuation) in the password portion. Even though
jq's @uri produced a syntactically valid encoded URL, pgloader decoded
it into a password that no longer matched what Postgres had, producing:

    Database error 28P01: password authentication failed for user "drupal_user"

Verified live: psql connected fine with the raw DRUPAL_DB_PASS, and the
env-file value byte-matched Secrets Manager — the ONLY layer failing was
pgloader's URL decode.

CFN's GenerateSecretString ExcludeCharacters
(`cf-app-drupal.yaml:141-150`) already prevents URL-hostile chars
(@, /, %, &, +, :, ;, =, ?, [, ], #, ~, etc.) from ever landing in
the password, so embedding the raw password directly in the URL is
safe. Encoding was introducing the bug, not preventing one.

## 2. Bump batch rows / prefetch rows 250 → 500

Progression:
  pgloader defaults (~25000 / 1000) → OOM on 2 GB swap on first run
  → 250 (safe, but conservative)
  → 500 (this run — Kurt's ask; 250 empirically ran comfortably in
    the 4 GB swap + workers=2/concurrency=1 envelope, so we can
    take on more batch throughput without memory risk)

Kept `workers = 2, concurrency = 1` — those constraints keep only one
table active at a time, capping worst-case memory to
    batch_rows × row_size × workers ≈ 500 × ~2KB × 2 ≈ 2 MB
per active table. Even for the widest Drupal tables that's a small
fraction of the SBCL heap.

## Files Modified

- migration/scripts/deploy-host/run-pgloader.sh (modified — drop
  DRUPAL_DB_PASS_ENC computation, export DRUPAL_DB_PASS raw)
- migration/pgloader/zinew.load.tmpl (modified — INTO URL uses
  ${DRUPAL_DB_PASS}, WITH clause batch/prefetch = 500)

Tests: bash -n clean; grep confirms no _ENC refs remain in either file
Docs: inline comments explain why raw is safe AND why encoded was broken
