Right — PHP boxes don't run nginx. Nothing on port 80 there. The probe file went onto FSx though, so any nginx box can serve it (nginx does `fastcgi_pass` back to the PHP-FPM upstream). Move to an nginx instance:

```bash
# Find an nginx instance:
aws --profile ZI-Sandbox autoscaling describe-auto-scaling-groups \
  --auto-scaling-group-names sandbox-nginx-asg \
  --query "AutoScalingGroups[0].Instances[?LifecycleState=='InService'].InstanceId" \
  --output text --region us-east-1

# SSM in to any one of them:
aws --profile ZI-Sandbox ssm start-session --target i-XXXX --region us-east-1

# From the nginx box:
curl -sS http://localhost/_env-probe.php
# (nginx will fastcgi_pass to a PHP-FPM worker, execute the probe, return output)
```

**One nuance to be aware of:** nginx doesn't necessarily route to the PHP box you're testing — it load-balances across all PHP-FPM instances via the NLB (or whatever your upstream is). Since you refreshed both php83 instances, both should have the env var, so the result is reliable. If you want to prove *both* have it, curl a few times and note if you see identical output every time.
