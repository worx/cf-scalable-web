## What comes after composer install

Rough sequence still inside Phase -1 (install-drupal):
1. Composer install ← **you are here**
2. Write settings.php (with our template — DB endpoints, hash salt, flysystem_s3, etc.)
3. `drush site:install` (creates the fresh Drupal DB tables in `zinew` schema, admin user, base config) — ~1-2 min
4. Post-install: cache rebuild, write `.installed` marker

Then Phase -1 exits → Phase 0 kicks in → migration proper begins.
