## The flysystem block alone isn't enough — need supporting config

Contrib module `drupal/flysystem_s3` typically needs a couple of additional lines to actually route s3:// URIs. Standard prod-side idiom looks like:

```php
$settings['flysystem'] = [ 's3' => [...] ];        // ← we have this
// … plus somewhere in prod's settings.php:
$config['flysystem.settings']['default_scheme'] = 's3';
$settings['file_public_scheme'] = 's3';
```

Without those, Drupal may register the s3:// scheme but never actually route file requests through it. Or it does, but a middleware controller expects the config value and NPEs when it's missing → "unexpected error."
