## Print / markup options

**Straight to paper** — Cmd+P from Preview.

**On the iPad** — AirDrop the PDF over. Then any of these give great markup:
- **GoodNotes 6** — best-in-class for reviewing long docs with Apple Pencil. Treats the PDF like a notebook, searchable handwriting, exports annotations. My pick for a doc this size.
- **PDF Expert** — pro-grade PDF editor. Comments, highlights, freehand.
- **Notability** — similar to GoodNotes.
- **Apple Books** — free, basic markup with Apple Pencil, good enough for light review.
- **Apple's Files → Preview** — free, quick highlights + notes.

**Direct MD markup on iPad** — you're right, that's a gap. iA Writer and Obsidian render MD beautifully on iPad but they're editors, not annotation tools. No real equivalent of PDF Expert for MD exists. Convert to PDF first.
