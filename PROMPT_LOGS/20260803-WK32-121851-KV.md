Yeah, Zed's markdown preview isn't optimized for print — same for most editors. Cleanest routes with pandoc:

## Recommended: MD → self-contained HTML → browser print

Zero extra dependencies beyond pandoc itself. Native macOS print dialog gives you paper size, margins, page-break control, save-as-PDF.

```bash
cd ~/Work/dev/cf-scalable-drupal

pandoc docs/plans/multi-tenant-refactor-review-2026-07-31.md \
  --standalone --toc --toc-depth=3 \
  --metadata title="Multi-Tenant Refactor Review — 2026-07-31" \
  --highlight-style=tango \
  --css=data:text/css,'body{max-width:7.5in;margin:0.5in auto;font-family:-apple-system,Helvetica,Arial,sans-serif;line-height:1.5;color:%23222}h1,h2,h3{page-break-after:avoid}table{page-break-inside:avoid;border-collapse:collapse;width:100%25}th,td{border:1px%20solid%20%23ddd;padding:0.4em%200.6em;text-align:left;vertical-align:top}pre,code{font-family:Menlo,monospace;font-size:0.85em}pre{page-break-inside:avoid;background:%23f6f8fa;padding:0.6em;overflow-x:auto}%40media%20print{a{color:inherit;text-decoration:none}}' \
  -o /tmp/multi-tenant-review.html

open /tmp/multi-tenant-review.html
# Cmd+P → "Save as PDF" or print directly
```

That inline CSS gives print-friendly widths, keeps tables/code-blocks from breaking mid-page, and adds the TOC pandoc generates.

## Alternative: MD → PDF directly

If you'd rather skip the browser step, you need a PDF engine. Two options:

**weasyprint** (modern, my recommendation — brew installs cleanly):
```bash
brew install weasyprint   # one-time

pandoc docs/plans/multi-tenant-refactor-review-2026-07-31.md \
  --standalone --toc --toc-depth=3 \
  --pdf-engine=weasyprint \
  -V margin-top=15mm -V margin-bottom=15mm \
  -V margin-left=18mm -V margin-right=18mm \
  -o /tmp/multi-tenant-review.pdf
```

**BasicTeX** (smaller than full mactex, ~100MB vs ~5GB):
```bash
brew install --cask basictex   # one-time (adds ~100MB)
# then in a NEW shell (BasicTeX prepends /usr/local/texlive to PATH):
pandoc docs/plans/multi-tenant-refactor-review-2026-07-31.md \
  --pdf-engine=xelatex \
  --toc --toc-depth=3 \
  -V geometry:margin=1in \
  -V documentclass=article \
  -V fontsize=11pt \
  -V mainfont="Helvetica Neue" \
  -o /tmp/multi-tenant-review.pdf
```

## If pandoc isn't installed

```bash
brew install pandoc
```
