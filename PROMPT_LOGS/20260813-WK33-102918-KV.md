### 10:29:49 - Response

Nailed it — **DivisionByZeroError in Drupal Commerce's DashboardMetricsForm**. Full picture:

```
bcdiv('546674.34', '0.000000', 6)
       ^current      ^prior period
       $546,674.34   $0.00
```

**What's happening:** the dashboard computes "percent change vs prior period" as `current / prior * 100`. Sandbox has real prod data for the CURRENT period ($546,674.34 of orders — nice sanity check that the migration landed real numbers), but the "prior period" window (a year ago) has ZERO orders because your prod-dump only has recent-ish data. `bcdiv(X, 0)` throws — the code has no guard clause for empty prior period.

**Location:** `commerce/modules/price/src/Calculator.php:96`, called from `DashboardMetricsForm::buildForm()` line 349.

**This is a Drupal Commerce upstream bug** — the DashboardMetricsForm's percent-change math doesn't handle empty prior periods. The one-line fix would be `if ($prior == 0) return $current > 0 ? 'new' : '—';` before the divide, but that's upstream code.

**Practical take:**

1. **Prod won't hit it** — prod has years of orders, so "prior period" always has data.
2. **Sandbox hits it because the migration is working correctly** — dashboard SEES real prod numbers for current period, sees ZERO for the year-ago period (because the dump doesn't cover that window). This error is actually a signal of a functioning migration.
3. **Do nothing** — curiosity satisfied. If you want to be a good citizen, file an issue on drupal.org against the commerce module. But it's not a "problem" in your system to fix.

**Bonus observation from the log:** the older errors (wid 29587, 29589) are `Notice: Only variables should be passed by reference` in `documents_file_update()` at `/var/www/html/zoning_info_platform/...`. Different path (`/var/www/html/...` vs `/var/www/drupal/...`) — those are **historical watchdog entries carried over from PROD's own DB dump**. Not from your sandbox at all; they're log entries prod generated at some point that got migrated along with the rest of the DB. Explains why they reference a path that doesn't exist on sandbox.
