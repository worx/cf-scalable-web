**Root cause found.**

Look at the module list output:
```
Other  Bundle Class Annotations  Disabled  1.1.1
```

The `bca` (Bundle Class Annotations) contrib module is installed in the codebase but **disabled** in sandbox's Drupal. That module's whole purpose (from its README): *"removes the need to implement hook_entity_bundle_info_alter()"* — it scans classes for a `#[BundleClass]` attribute and auto-registers them. Prod has it enabled → bundle classes work. Sandbox has it disabled → base `ResearchDocument` gets used for every bundle → `getResearchAnswer()` missing → crash.

Why the state differs: your sandbox's `core.extension` config either predates when `bca` was added to prod, OR the migration didn't overwrite that particular config, OR someone manually disabled it on sandbox at some point. Doesn't really matter *why* — the fix is one command.

## Fix
