### 19:57:49 - Response

Three commands via `make ssm-jumpbox`:

```bash
sudo timedatectl set-timezone America/Chicago
sudo systemctl restart cron
timedatectl status   # verify — should show "Time zone: America/Chicago (CDT, -0500)"
```

`America/Chicago` handles CDT/CST + DST transitions automatically. `restart cron` is important — cron reads the timezone at startup and won't pick up the change without it.

After that, your `0 3 * * 2-6` cron entry fires at 3am Central. Same crontab, correct wall-clock time.
