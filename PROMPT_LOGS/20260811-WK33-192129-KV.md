### 19:29:34 - Response

**Short version:** you're not double-billed. The ~$60/mo IS one thing — nine Interface VPC Endpoints @ ~$7.20/mo each — and it's intentional.

**Where the 9 endpoints come from:**

| What it enables | Endpoints | Cost |
|---|---|---|
| SSM into private-subnet instances (nginx, PHP-FPM) | SSM + SSMMessages + EC2Messages, ×2 AZs = 6 ENIs | ~$43/mo |
| PHP-FPM workers reading DB creds at boot | SecretsManager ×2 AZs = 2 ENIs | ~$14/mo |
| Drupal outbound email | SES SMTP ×1 AZ (SES's regional limit) = 1 ENI | ~$7/mo |

**Why endpoints instead of a NAT Gateway** — the trade Kurt made when the VPC was designed:
- NAT Gateway: ~$32/mo flat + $0.045/GB. Simpler, but private subnets can reach the whole internet.
- Endpoints: ~$65/mo for these 9 + $0.01/GB. More expensive, but private subnets can ONLY reach the specific AWS services we whitelisted. Compromised instance can't exfiltrate anywhere else.

So we're paying ~$33/mo extra vs a NAT model to buy "no arbitrary outbound." Whether that's worth it is a security-posture judgment call, not a bug.

**On your "$37/mo for a VPC" memory** — nothing in AWS pricing actually looks like that. The VPC itself, subnets, route tables, security groups, and internet gateway are all **free**. The closest match to "$37" is a NAT Gateway (~$33). Possible you were remembering a NAT figure and thinking of it as a VPC baseline.

**What's NOT on that $60 line** but is also billed to the same VPC:
- ALB: ~$16/mo + LCU
- NLB: ~$16/mo + NLCU
- Public IPv4 on deploy-host: ~$3.60/mo (~$7 when migrate-host is also up)
- S3 gateway endpoint: **free**
- Route 53: **$0** — the zone lives in a different account, not billed here

Total base network across all shown lines: ~$100/mo per env. Bursty use (destroy-all between tests) gets you back to near-zero cost during idle periods.

```

```
