## Proper fix (follow-up, not now)

The check `[ -f /var/www/drupal/.installed ]` is brittle because the marker gets missed on installs that predate the marker convention (like your sandbox). A structural check would be more reliable:

```bash
[ -x /var/www/drupal/vendor/bin/drush ] && \
[ -f /var/www/drupal/web/sites/default/settings.php ]
```

If drush AND settings.php exist, Drupal is deployed — that's the actual precondition. And that's what admin-login-url actually NEEDS anyway (it invokes drush). Zero false negatives on legacy installs.

Better yet: on any script that needs the check, invert it — try to run drush; if drush fails cleanly with a specific error, THEN say "Drupal not installed." Symptom-driven, not marker-driven.
